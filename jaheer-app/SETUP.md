# إعداد منصة أكاديمية جَهير

> **لا تنشر على الإنتاج قبل اتباع هذه الخطوات واختبارها.** هذا المجلد مستقل عن مشروعك الحالي المنشور، ولا يغيّره حتى تدمجه أنت.

## 0) ما الذي يتغير في مشروعك الحالي؟
المنصة الجديدة تحل محل: `index.html` (الصفحة الواحدة)، و`register.html` و`judge.html` و`my-notes.html`، و`assets/portal.*`، و`supabase/schema.sql` القديم، و`vercel.json` القديم.
**نفس مشروع Vercel ونفس الرابط:** انسخ محتويات هذا المجلد إلى مستودع GitHub الحالي (احذف الملفات القديمة المذكورة)، ثم يتولى Vercel النشر التلقائي كالمعتاد. جرّب أولًا على فرع منفصل (Preview Deployment) قبل الدمج في `main`.

## 1) قاعدة البيانات (Supabase)
1. إن كنتَ نفّذتَ `schema.sql` القديم (جداول participants / judges / feedback) ولا بيانات حقيقية فيها، فنظّفها أولًا (**يحذف بياناتها نهائيًا**):
   ```sql
   drop table if exists public.feedback, public.judges, public.participants cascade;
   drop function if exists public.is_judge(), public.list_participants(), public.my_feedback(), public.handle_new_participant() cascade;
   ```
2. **SQL Editor ← New query**: الصق `supabase/schema.sql` كاملًا ← **Run**. (ينشئ الجداول والصلاحيات والمشغّلات والبيانات الأولية.)

## 2) ربط الواجهة
في `assets/config.js` ضع **Project URL** و**anon public key** (من Project Settings ← API). هذان عامّان بطبيعتهما. **لا تضع service_role هنا أبدًا.**

## 3) متغيرات Vercel (للخادم فقط)
Vercel ← Project ← Settings ← Environment Variables:
| الاسم | القيمة |
|---|---|
| `SUPABASE_URL` | نفس Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح service_role (سري) |

لا تضف بادئة `NEXT_PUBLIC_` أو `VITE_` إطلاقًا. المفتاح يُستخدم فقط في `api/invite-judge.js` على الخادم.

## 4) إعدادات المصادقة في Supabase (Authentication)
- **URL Configuration:** *Site URL* = رابط موقعك. أضف في *Redirect URLs*: `https://رابطك/verify-email` و`https://رابطك/reset-password`.
- **Providers ← Email:** فعّل *Confirm email*. أبقِ مزوّد الهاتف (Phone) **معطّلًا**. الحد الأدنى لكلمة المرور 8 أو أكثر.
- **Attack Protection:** فعّل CAPTCHA لمنع التسجيلات الوهمية.
- **SMTP:** اربط بريدًا خاصًا؛ البريد الافتراضي محدود جدًا.
- **Email Templates ← Invite user:** عدّل نص دعوة المحكّم إن شئت (رابط الدعوة يفتح `/reset-password` لتعيين كلمة المرور).

## 5) أول مشرف
1. سجّل حسابك من `/register` وأكّد بريدك.
2. في SQL Editor (بدّل البريد):
   ```sql
   update public.profiles set role = 'admin' where email = 'your@email.com';
   ```
3. سجّل الدخول وسيحوّلك الموقع إلى `/admin/dashboard`. من هنا تُدار كل الأقسام دون تعديل الكود.

## 6) المحكّمون
من `/admin/judges` ← «دعوة محكّم». تصل الدعوة بالبريد، ويعيّن المحكّم كلمة مروره بنفسه. لا يمكن لأحد التسجيل كمحكّم من الواجهة العامة.

## 7) قائمة اختبار قبل النشر (بحسابات حقيقية)
1. سجّل مشاركَين، وتأكد أن دور كلٍّ منهما `participant` في جدول profiles.
2. ادع محكّمًا وأنشئ فعالية مفتوحة مع معايير، وسجّل المشارك فيها واقبله من `/admin/events/[id]`.
3. أنشئ تكليفًا (محكّم ← مشارك) من `/admin/assignments`.
4. من حساب المحكّم: احفظ مسودة ثم سلّم التقييم. تأكد أنه لا يعدَّل بعد التسليم.
5. من المشرف: `/admin/results` ← احسب ثم انشر. تأكد أن المشارك يرى الدرجات والملاحظات **دون اسم المحكّم**، ولا يرى تقييم مشارك آخر.
6. جرّب أن المشارك لا يفتح `/admin/*` و`/judge/*` (يظهر 403)، وأن المحكّم لا يفتح تكليف غيره (404).
7. افتح كل رابط مباشرة وحدّث الصفحة، وجرّب الخروج ثم زر الرجوع.

## ما لم يُنفَّذ (لأنه يحتاج قرارًا أو خدمة)
- **نموذج تواصل:** غير موجود (لا توجد خدمة بريد مهيّأة). صفحة `/contact` تعرض البريد والروابط الرسمية فقط.
- **رفع الصور:** المعرض يقبل روابط `https` لملفات مستضافة، ولا يرفع ملفات (يتطلب Supabase Storage).
- **إشعارات بريدية** للمشاركين عند قبول الطلب أو نشر النتائج: غير موجودة (الإشعارات داخل لوحة المشارك فقط).
- **تغيير كلمة المرور من الملف الشخصي:** غير موجود؛ يتم عبر «نسيت كلمة المرور».
- **حذف حساب/تصدير بيانات المستخدم:** يدويًا من لوحة Supabase.

## قيود معروفة
- الموقع **تطبيق من جهة المتصفح** بمسارات حقيقية: المسارات غير الموجودة تعرض صفحة 404 لكن بحالة HTTP 200، ومحركات البحث ترى المحتوى بعد تنفيذ JavaScript فقط.
- مكتبة `supabase-js` تُحمَّل من CDN (jsDelivr) بإصدار مثبّت وبلا بصمة SRI. الأمثل لاحقًا استضافة الملف داخل المشروع.
- لا تضع أسرارًا في جدول `settings`؛ قراءته عامة.
