# أكاديمية جَهير — Jaheer Academy

موقع ثنائي اللغة (عربي / English) من ملف واحد: `index.html`. لا يحتاج بناءً ولا مكتبات.

## النشر
- **Vercel:** استورد المستودع من GitHub واضغط Deploy. اترك إعدادات البناء فارغة.
- **GitHub Pages:** Settings ← Pages ← Deploy from a branch ← main / root.

## تعديل المحتوى (داخل `index.html`)
- **الصور والشعارات والروابط:** الكائن `M` في أعلى السكربت. ضع مسار الملف، مثل `"assets/hero/cover.jpg"`.
- **النصوص:** الدالة `T`، كل نص بصيغة `p("العربية","English")`. النص بين `[ ]` مؤقت.
- **الشعار الكتابي:** المصفوفة `SLOGAN` — لا تُعدَّل.

## مجلد الصور `assets/`
`logo` الشعارات · `hero` صورة الغلاف · `colors` صور الألوان الأربعة ·

صيغ مقترحة: JPG/WebP بعرض لا يتجاوز 1600px لتسريع التحميل.

## التسجيل وملاحظات المحكّمين
راجع `SETUP-DATABASE.md` (قاعدة بيانات Supabase، ملف `supabase/schema.sql`).
